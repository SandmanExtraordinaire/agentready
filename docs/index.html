Can AI agents shop your store?

Agent Ready scans a commerce site the way a shopping agent meets it: can it get in, understand the catalogue, talk to the store, and reach checkout. The result is a maturity tier, a score and a prioritised fix list.

InvisibleAgents are blocked or can’t read product pages
ReadableAgents get in and read content without JavaScript
DiscoverableAnswer engines understand products, prices and stock
TransactableAn agent can reach checkout, by site or by UCP
Agent-nativeLive UCP checkout plus a store agent or MCP server

What it checks

Agent access

robots.txt rules for 15 AI agents, and whether bot protection treats agents differently from browsers. Blocking training crawlers isn’t penalised.

Commerce protocols

The UCP profile at /.well-known/ucp, validated against the release it declares, with every endpoint probed. ACP is reported as signals, since it can’t be verified from outside.

Agent-to-agent

A2A agent cards, MCP servers (with a read-only handshake that lists their tools) and on-site assistants.

AI discoverability

Product markup completeness, GTINs, return and shipping policies, ratings, price consistency, brand identity, sitemaps and llms.txt.

Works without JavaScript

Whether name, price and markup exist before scripts run. Most AI fetchers never execute JavaScript.

Task completion

A headless agent adds one item to the cart and opens checkout, then stops. It never enters details or pays.

Run a scan

  1. Install the scanner and, for the journey checks, a headless browser. 
    pip install -e '.[browser]'
playwright install chromium
  2. Scan a store, optionally against competitors. 
    agentready scan client.com --vs rival-one.com --vs rival-two.com
  3. Open the HTML file in reports/. Reports stay on your machine and are never committed.

What a scan can’t tell you

Bot-protection results use AI agents’ user-agent strings from our own IP address. Real agents can be verified by IP or signature and treated differently, so these findings are marked as inferred.

ACP (ChatGPT checkout) integrations are private between the merchant, OpenAI and Stripe. The scan reports signals; confirm enrolment with the client.

Whether ChatGPT, Gemini or Perplexity actually recommend a brand needs their APIs, and is planned as a later module.

Agent Ready scans politely: one request at a time per site, a small sample of pages, and nothing transactional.
