How to read this

Tiers are gates, not score bands: a store reaches a tier only when it meets that tier and every tier below it. The score weights six areas: agent access 25%, commerce protocols 20%, agent-to-agent 10%, ai discoverability 20%, works without javascript 10%, task completion 15%.

Lines marked “inferred” are strong signals rather than proof. Bot-protection results come from requests using AI agents' user-agent strings; real agents may be verified by IP address or signature and treated differently. ACP (ChatGPT checkout) integrations are private, so they can only be inferred from the outside.

The journey probe adds one item to the cart and opens checkout, then stops. It never enters personal details, submits a form or pays.
